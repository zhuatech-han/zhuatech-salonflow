# 安全与数据保护

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 商业授权与定制开发微信：zhuatech / zhuatech2

账号BCrypt成本12，强密码12–72字符/UTF-8字节上限72且需大小写与数字；无共享管理员密码。Session HttpOnly、SameSite=Strict，HTTPS部署Secure，30分钟超时。CSRF覆盖登录/注册及其他写请求，退出失效。

数据权限服务器每请求复核：客户本人、员工被指派、前台/店长门店、管理员ALL。匿名目录不暴露联系方式、账号或预约。密码哈希被JSON忽略。内建客户角色固定，最后有效管理员保护，关联业务账号身份受锁定。密码变更后的旧会话拒绝，停用和权限变更立即按当前数据库授权检查。

登录失败8次/5分钟与注册10次/IP/小时为进程内限流，公开入口仍需可信代理、网络频率限制与监测。客户邮件同意存储但**没有验证邮箱所有权**；部署者应评估滥用风险，商业使用可补邮箱核验和更完善验证流程。纯浏览器同源操作，URL勿嵌入凭证。

输入有长度、数值、整数、日期和状态校验。JPQL参数绑定，资源白名单，数据库外键和命令指纹。CSV防常见公式首字符；导出的姓名备注仍属业务数据，应限定保存与转发。客户JSON导入限制1–500条及Nginx请求体大小，不提供任意文件下载。

真实密钥、.env、Cookie、SMTP密码、客户数据、备份和未经脱敏日志不得入Git。例邮箱只用example.invalid；测试截图标TEST虚构数据。SMTP测试仅连隔离本机收件器，不访问真实邮箱或付费服务。

公开部署管理员角色、门店范围和数据库权限应最小化；采用HTTPS、外部数据库TLS证书核验、私有备份、恢复演练、按实际运行维护更新。学习版不宣称已通过渗透测试、安全认证或医疗/支付合规审查。
